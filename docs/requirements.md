# Соответствие заданию

Источник: сборник индивидуальных вариантов №1, ИКБО-71-24, с. 4–5 и 72–74.

| Требование | Реализация и проверка |
|---|---|
| Схема рисунка 23 | schema.py; точные поля и типы трёх таблиц |
| Записи представлены списками | Store хранит list, возвращает копии list |
| Создание, все записи, запись по uid | девять явных методов Store |
| Реляционная выборка | recent_results, строгие 9 минут, DISTINCT |
| REPL модели | ./run.sh model, ошибки не завершают цикл |
| Демонстрация всех операций и ошибок | demo.py; локальный REPL и сетевой demo |
| Коммит этапа 1 | feat(model) в истории git |
| TCP RPC всех 10 операций | server.py, client.py, operations.py |
| XML, запрос 1+2+4, ответ 1+1+5 | codec.py, protocol.py; буквальные байтовые тесты |
| Big-endian | to_bytes/from_bytes с big |
| Журнал запросов и ответов в stdout | REQUEST, REQUEST_ERROR, RESPONSE, SEND_ERROR |
| Имена методов клиента как у модели | 10 явных совпадающих методов RpcClient |
| Демонстрация клиента | ./run.sh demo через реальный TCP |
| Коммит этапа 2 | feat(rpc) в истории git |
| RuleBasedStateMachine | tests/test_mbt.py, независимый эталон |
| 10 методов только тестами Hypothesis | отдельный coverage --branch и check_mbt_coverage.py |
| Коммит этапа 3 | test(mbt) в истории git |
| README, .gitignore, src, tests, запуск | присутствуют; Linux run.sh и Windows run.bat |
| Conventional/Scoped Commits | feat(model), feat(rpc), test(mbt), docs(report) |
| Нет бинарных и служебных файлов в git | .gitignore; проверка git ls-files |
| Файлы <=1000, строки <=80, функции <=40, аргументы <=7 | tests/audit_project.py |
| Только docstring вместо # комментариев | tokenize-проверка в audit_project.py |
| PEP8 и сложность | ruff E/F/W/N/C90, максимальная сложность 10 |
| Публичный git-репозиторий | требуется публикация подготовленного локального репозитория |

Вариант не задаёт формат XML-элементов, числовые коды операций, способ
назначения ключей и соглашения об ошибках. Эти решения явно описаны в README.
Не добавлены удаление/редактирование: перечисление операций конкретного
варианта имеет приоритет над общим описанием «чтение и редактирование».

Отчёты и архив не включаются в git. Они выдаются отдельно. Очная защита и
публикация по публичной ссылке не подменяются успешным локальным запуском.
